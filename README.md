# ScholarSphere

ScholarSphere is a frontend-only React education platform built for academic research and UI comparison. It uses local static data, React Router, reusable components, and responsive CSS to present a polished university-style learning experience.

## Tech Stack

- React
- React Router
- Vite
- Standard CSS
- React Icons

## Project Structure

- `src/App.jsx` - Main router and global layout
- `src/main.jsx` - React entry point
- `src/components/` - Reusable UI components
- `src/pages/` - Route pages
- `src/data/courses.js` - Local course, FAQ, testimonial, and service data
- `src/styles.css` - Global styling and responsive layout rules
- `public/images/` - Local image assets

## Running Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
